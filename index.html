FOUR SCREENS. ONE EXPERIENCE.

The scope is already clear.

React Native Reanimated Haptics 25-minute sessions

01 / Splash

A four-second arrival, without chrome.

A soft gold orb with a dark core sits on the night field. The camera stays still. The orb breathes once, swelling, holding, then settling before easing into Home. Reanimated keeps the motion smooth. A still image is only the resting frame.

02 / Home

One timer, visible time left, real control.

The orb keeps a slow breath behind a 25-minute timer. Start and pause work for real, the ring reflects time remaining, and a light haptic marks the start of each session.

03 / Done

A finish worth waiting for.

When the session ends, the orb breaks into gold particles and a single comet crosses the night field. After roughly three seconds, the app resolves into a quiet completion state and a clear way back to Home.

04 / Settings

Only the preferences that belong.

Haptics on or off. A daily goal. Nothing else competing for attention, and no onboarding, profile, journal, or account layer added around the core ritual.

FAQ

A few useful boundaries.

Will the splash and completion moments actually animate? +

Yes. The intended build uses Reanimated for the breathing orb on Splash and Home, then the gold particle burst and comet sequence when a session completes.

Is this a full productivity platform? +

No. Lumen Drift stays a focus timer. The first release is deliberately limited to Splash, Home, Done, and Settings.

Will start, pause, haptics, and the timer ring be functional? +

Yes. These are core interactions, not a static prototype. Home is designed around a real 25-minute session, visible time remaining, start and pause control, and a light start haptic when enabled.

What is intentionally left out? +

Sign-in, onboarding, profiles, journals, and additional app screens stay out of scope. Settings only handles haptics and the daily goal.
